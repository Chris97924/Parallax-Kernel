## Conventions observed
- Migration pattern: parallax/migrations/m00NN_name.py exports STATEMENTS list + up(conn)/down(conn). Register in parallax/migrations/__init__.py MIGRATIONS list + _MIGRATION_MODULES dict.
- Route pattern: APIRouter(prefix=..., tags=..., dependencies=[Depends(require_auth)]). Register via app.include_router() in parallax/server/app.py create_app().
- Auth: require_auth from parallax.server.auth handles both single-token and multi-user modes; current_user_id(request, fallback) resolves authenticated principal.
- Testing: pytest; tests live in tests/, tests/server/, tests/integration/; coverage gate 80% enforced in pyproject.toml addopts.
- Existing MEMORY.md uses `# Section` markdown headers (H1). Companion files use `---\nname:\ndescription:\ntype:\n---\nbody` YAML-ish frontmatter.
- `parallax/ingest.py` exists as a module — could not make `parallax/ingest/` a package. Put memory_md logic at top-level `parallax/memory_md.py` instead.
- Hook timeout in settings.json is in SECONDS (e.g. "timeout": 5 is 5s), not ms. Used timeout: 2 for regenerate hook.

## Design decisions (resolved)
1. `parallax/ingest/` package collision — used top-level `parallax/memory_md.py` instead.
2. Privacy filter: substring match as specified. `token` in body filters the longmemeval card (expected per spec).
3. Hook script: stdlib-only; kwargs on main() for test injection; Phase 2 guard logs 'phase2_not_enabled' if someone sets DRY_RUN=0.
4. Export rendering: name field from DB (companion frontmatter name), not the MEMORY.md link label — round-trip correct for re-ingest.
5. conftest.py guards coverage gate for test_regenerate.py-only runs (script lives outside the parallax package; covering it would not move the parallax coverage number anyway, and we didn't want test-file-scoped runs to fail the gate).
